# Benchmarks de Desempenho

Esta pasta concentra os scripts de benchmark de desempenho do núcleo do grafo e dos algoritmos (M2), incluindo a comparação com o **NetworkX** exigida pelo enunciado.

> **Regra do projeto:** `benchmarks/` é o **único** diretório do repositório onde a importação de `networkx` é permitida (verificada automaticamente via Ruff `TID251` e `pytest`).
